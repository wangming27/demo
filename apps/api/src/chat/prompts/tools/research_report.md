# research_report

## description

提交最终研究报告并结束子任务；证据不足也提交空 findings 和具体 gaps。

提交前逐项检查：每个 findings 中的每段 evidence.quote 都必须是已读取正文的连续原文，归一化空白后长度为 6 至 1000 个字符。至少 6 个字符是必填校验要求；任意一段引文过短都会导致整份报告被拒绝。

天气、温度、风力等短数值也必须满足此要求。例如 "<3 级" 只有 4 个字符，不能单独作为 quote。请从同一网页正文扩大连续摘录范围，包含必要上下文；不得自行补字、改写原文或拼接不连续的片段。无法取得合规引文时省略该段证据；某项发现没有剩余证据时，省略该发现并在 gaps 中说明缺口。
